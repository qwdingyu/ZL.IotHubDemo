    Class FatekTcpDriver

    永宏 FATEK FBs 系列 PLC TCP 驱动（标准编程口 ASCII 协议，透传）。

    帧格式：[STX(0x02)][站号(2)][命令串(ASCII)][LRC(2)][ETX(0x03)] 成功响应：[STX][站号][命令回显(2)][状态'0'][数据][LRC][ETX]； 状态码非 '0' 时为细分错误（2/3/4/5/6/7/9/A）。
