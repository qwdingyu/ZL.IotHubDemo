    Classes

    InovanceAddressMapper

    汇川 Inovance 地址映射器。

    支持 AM / H3U / H5U 系列，地址格式：

    • D100 — 数据寄存器（FC3/FC6/FC16）
    • M0 — 内部辅助继电器（FC1/FC5/FC15）
    • X5 — 输入点（八进制，FC2）
    • Y10 — 输出点（八进制，FC1/FC5/FC15）
    • S100 — 状态继电器（FC1/FC5/FC15，仅 H3U/H5U）
    • T0 — 定时器线圈/当前值
    • C0 — 计数器线圈/当前值
    • SM0 — 特殊辅助（AM 专用）
    • SD0 — 特殊数据（AM 专用）
    • MB0 — 字中的字节（偶数地址）
    • MW0 — 字
    • MD0 — 双字

    InovanceTcpDriver

    汇川 Inovance PLC Modbus TCP 驱动。

    支持 AM / H3U / H5U 系列。 地址格式：D100, M0, X5, Y10 等符号地址。

    字节序：汇川使用 CDAB（字内字节交换），见 CdabEndianConverter。
