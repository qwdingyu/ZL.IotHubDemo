    ModbusRtuDriver

    Modbus RTU 串口驱动（基于 System.IO.Ports.SerialPort）。

    通过串口（RS-232/RS-485）与 Modbus RTU 从站通信，实现 IPlcDevice 接口。

    地址格式说明（五位数地址码）：

    • 00001～09999 — 线圈（功能码 01/05/15）
    • 10001～19999 — 离散输入（功能码 02）
    • 30001～39999 — 输入寄存器（功能码 04）
    • 40001～49999 — 保持寄存器（功能码 03/06/16）
    • 0～65535 — 直接使用原始地址，默认保持寄存器
