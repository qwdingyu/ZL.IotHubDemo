    Interface IMultiTagReader

    可选能力接口：驱动支持"一次协议往返读多个标签"时实现它。

    Namespace: ZL.IotAbstraction.Abstractions
    Assembly: ZL.IotAbstraction.dll
    Syntax
    public interface IMultiTagReader
    Remarks

    为什么另开接口，而不改 IPlcDevice：纯加性、零破坏 —— 62 个既有驱动不必改动；编排层用 device is IMultiTagReader 探测（与 IBitBatchReader 同一模式 ✓）。

    为什么需要它：BACnet 现场几乎默认用 **ReadPropertyMultiple(RPM)** 批量读； 逐点 ReadProperty 的往返次数 = 标签数 ⇒ 大点表下延迟线性增长 ✗。 有了本接口，驱动可把"同一对象的多个属性"合并成 1 次 RPM ✓ （实测：`analogValue,1` 的 presentValue/units/objectName 一次取回，见 `docs/drivers/Bacnet.md` §9.2）。

    契约（务必逐条遵守）：

    • length 仍是**字节数**（AGENTS §21.1），与 ReadBytes(string, ushort) 同义 ✓
    • 返回值**只含成功项**；失败的标签**不进字典**（调用方可对其回退单点读）—— 不做"失败填 null"的含糊表达 ✓
    • **不抛异常**；协议级失败用 Fail(string, int, DeviceFailureKind, FailureOwner, string) 表达 ✓
    • 同一标签重复出现时**后者覆盖前者**（调用方不应重复）✓
