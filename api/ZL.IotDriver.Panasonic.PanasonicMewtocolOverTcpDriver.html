    Class PanasonicMewtocolOverTcpDriver

    松下 Mewtocol 串口转网口驱动（串口帧经 TCP 透传，"串口服务器"形态）。

    【2026-10-26 新增，docs/todolist ④ 第二步】协议帧构建 / 收帧 / BCC 校验 **单源复用** PanasonicMewtocolDriver（本类只覆写传输层 3 缝与连接管理 ✓， 避免复制 ~300 行协议逻辑 ✗）。

    【为什么要有它】串口协议的第三方交叉此前因"我方驱动只有 COM 形态"而缺位 （docs/486 §四.0）；HSL 的串口协议服务端支持 TCP 透传 （DeviceServer.ServerStart(port)，已由 SerialProtocolHslServerCrossTests 自环实证 ✓）⇒ 本变体可直接对拍 HSL 服务端，零 PTY / 零新依赖 ✓。

    【传输语义对齐串口 ✓】 · 写前排空残留（对齐 SerialPort.DiscardInBuffer 的意图：防上次超时的 残留字节造成帧错位 ✗）； · 读超时 = System.Net.Sockets.NetworkStream.ReadTimeout ⇒ System.IO.IOException 由 ReadBytesCore 的统一 catch 转 Fail（与串口超时同契约 ✓）； · 远端关闭 ⇒ ReadByte 返回 -1 ⇒ 收帧循环退出（与串口 EOF 同语义 ✓）。
