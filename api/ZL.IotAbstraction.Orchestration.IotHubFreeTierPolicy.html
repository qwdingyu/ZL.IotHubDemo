    Class IotHubFreeTierPolicy

    ZL.IotHub 免费版策略。

    业务意图：在 LicenseManager 通用授权检查之上，增加产品级免费版限制。 免费版规则： 1. 设备数上限 10 台—— 属于准入语义：只在"创建第 N+1 台"时经 ZL.License.LicenseManager.IncrementDeviceCount() 判一次 （超限抛"试用态设备数已达上限"并原子回滚）； 绝不放在每报文/每构造的通信门禁通路上 —— 历史缺陷：计数在设备已存在时就 +1，`>=` 判定放在通信通路上的语义变成 「已有设备数 ≥ 上限 ⇒ 连已有设备也不许通信」； 2. 不限协议； 3. 允许读写（ 定型放开写入；原"仅允许读取"由 L3 AllowWrite 收口，未来如需恢复禁写 只需在 LicenseGate.AllowWrite 加回 Trial 守卫）； 4. 必须具有 BasicRead 功能位。

    生效前提：本策略仅在试用（Trial）态由 LicenseGate 叠加； 正式授权（Authorized）的设备额度与功能位由授权文件承担，不再被免费版策略误伤。

    IsAllowed(string?)

    判断当前操作是否允许在免费版下执行（通信放行语义）。

    2026-09-19 修复：移除设备数判定 —— 该判定曾用 ActivatedDevices >= 上限 跑在每报文/每构造通路上， 而计数在设备已存在时就已 +1，导致「建满后已有设备被自己门禁拒掉」。 设备数属于准入语义，统一由 ZL.License.LicenseManager.IncrementDeviceCount() 在创建驱动时 原子判定（超限抛 ZL.License.LicenseException 并回滚），本方法只承担： 未知协议写入禁止（保守启发式）/ BasicRead 功能位。

    2026-09-23：免费版不限协议 —— 移除 HSL 禁令 。自研 Native 全部 + HSL（hsl-*）全部放行； HSL 商业库自身的授权码机制（XInit/ZL_XAUTH_HSL）不受本策略影响，由驱动连接时另行校验。
