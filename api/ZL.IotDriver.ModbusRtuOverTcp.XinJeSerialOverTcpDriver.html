    Class XinJeSerialOverTcpDriver

    信捷（XinJE）Modbus RTU over TCP（串口服务器透传）驱动。

    帧格式 = 标准 Modbus RTU over TCP（继承 ModbusRtuOverTcpDriver， 零帧逻辑复制）✓

    地址格式 = 信捷符号地址，由 XinJeAddressMapper 转换， **与 `xinje-tcp` / `xinje-serial` 使用同一个映射器** ✓
