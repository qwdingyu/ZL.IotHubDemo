    Class MegMeetAddressMapper

    麦格米特 MegMeet 品牌地址映射。

    规则**逐条对应** HSL `MegMeetHelper.PraseMegMeetAddress`： 位操作与寄存器操作**两套偏移不同**，必须按 `functionCode` 区分 [OK]

    位操作功能码：`1`(读线圈) / `15`(写多线圈) / `5`(写单线圈)； 其余（`3`/`4`/`6`/`16` 等）走寄存器规则。
