    IsRetryable(DeviceFailureKind, int)

    该失败是否值得重试（同一参数再试一次是否可能成功）。

    🔴 判据（按"重试能否改变结果"划分，不是按"严重程度"）： · 参数/地址/不支持/已释放 ⇒ **重试不会改变结果** ⇒ false ✓ · 未连接/超时 ⇒ 环境问题，可能自愈 ⇒ true ✓ · 数据异常 ⇒ 可能是一时干扰 ⇒ true ✓ · 设备拒绝 ⇒ **默认 false**（设备已明确答复）✓ · 未分类/其它 ⇒ **默认 true**（保守：宁可多试一次，也不要把可恢复的当永久故障）✓
