    Class PlcNotificationHubMetrics

    通知中枢运行指标快照。

    用于工业现场的可观测性与诊断： - 运维人员可通过指标判断中枢是否健康（积压、丢弃、回调异常）； - 性能调优时可观察 CatchUp 耗时、缓冲利用率； - 对接 Prometheus/Grafana 等监控系统时，这些指标是核心数据源。
