    Enum LogLevel

    日志级别。数值越大越严重；Off 表示关闭。

    ⚠️ 成员**名称**与 NLog 保持一致（下游从 NLog 迁移时 `LogLevel.Info` 等写法不用改）， 但类型是本仓自有的 ⇒ 不再需要 NLog 包 ✓。

    Name Description
    Debug

    调试信息。
    Error

    错误：当前操作失败。
    Fatal

    致命错误：进程可能无法继续。
    Info

    常规信息（默认级别）。
    Off

    关闭日志（MinLevel 设为它即全关）。
    Trace

    最详细的跟踪信息（通常只在排查时开启）。
    Warn

    警告：可继续运行，但需要关注。
