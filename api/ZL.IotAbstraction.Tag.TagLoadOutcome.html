    ⚠️ **2026-11-10 更正（此处原写过时内容）**：原文写"漏写 `Enable="true"`"是第三类成因， 理由是三格式默认值**不一致**（XML=false、CSV/JSON=true）✗ **三格式已统一为 `true`**（`TagItem.DefaultEnable`）⇒ **"漏写 `Enable`"不再导致 0 条** ✗ ⇒ 现场若只看旧文案，会把排查方向**指错**（去补 `Enable` 而问题其实是子元素名写错）✗
