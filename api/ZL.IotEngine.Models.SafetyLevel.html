    Enum SafetyLevel

    PLC 写入操作的安全等级分级——数值越小优先级越高。

    在工控场景中，向 PLC 写入数据必须按安全等级分级管控： - 紧急停止类操作（如复位安全标志）必须立即执行，不可排队或合并； - 过程控制类操作（如写入配方参数）需要保证顺序和完整性； - 普通操作（如 HMI 手动设值）可以合并去重以减轻 PLC 通讯压力。

    数值设计采用"越小越优先"的方式，便于在优先级队列中用最小堆排序。
