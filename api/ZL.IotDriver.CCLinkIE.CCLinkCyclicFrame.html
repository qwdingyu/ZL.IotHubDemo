    BuildTransmissionState(int, bool)

    构造"指定占用站参与周期通信"的 cyclic_transmission_state 位掩码。

    **依据**：`cl_iefb_set_cyclic_transmission_state`（cl_iefb.c:795-817）—— `mask = BIT(slave_station_no - 1)`，`state=true` 则置位、`false` 则清位； 站号范围 1..16（超出则忽略）。

    **语义**：bit(n-1) = 第 n 个**占用站**是否参与周期通信（1=参与，0=停止）。 例如 2 个占用站都参与 => `0b11` = 0x0003。
