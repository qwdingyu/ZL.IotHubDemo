    Class MeterBcd

    DLT645 / CJT188 等计量表协议的 BCD 数值编解码（低字节在前）。

    这些协议的响应体是 BCD、低字节在前，且每 DI 的小数位不同。 本类把它们做对：反序 → BCD→整数 → ÷10^digit，写方向做完全对称的反算。

    典型用法（读）：

    var raw = device.ReadBytes("000000000001;02010100", 2);   // 原始字节，如 {0x11,0x23}
if (raw.IsSuccess) {
    decimal volt = MeterBcd.ToEngineering(raw.Content, decimals: 1);   // 231.1m
}

    典型用法（写）：

    byte[] wire = MeterBcd.ToWire(231.1m, byteLength: 2, decimals: 1);     // {0x11,0x23}

    [!] 本类**不做**"用户自定义换算"（乘系数/加偏置）—— 那是 ValueScale 的职责，两者语义不同，不要混用。

    ToEngineering(byte[], int, bool)

    把线上字节解码为工程值：BCD(reverse(wire)) / 10^decimals。

    实测对照（与仿真器/HSL 一致）：

    • `{0x11,0x23}` + decimals=1 ⇒ **231.1**（DI 02010100 A 相电压）
    • `{0x45,0x23,0x01}` + decimals=3 ⇒ **12.345**（DI 02020100 A 相电流）
    • `{0x56,0x34,0x12}` + decimals=4 ⇒ **12.3456**（DI 02030000 总有功）

    ToWire(decimal, int, int, bool)

    把工程值编码为线上字节（写方向，与 ToEngineering(byte[], int, bool) 完全对称）。

    算法：`|value| × 10^decimals` 取整 → 按字节数转 BCD → **反序**（低字节在前）。

    [!] 舍入语义（必须明确，否则计量场景会算错账）： 缩放后**不是整数时按 `MidpointRounding.AwayFromZero` 舍入**（远离零），例如 `ToWire(231.15m, 2, 1)` ⇒ `231.15 × 10 = 2311.5` ⇒ 取整 **2312** ⇒ 线上 `0x12 0x23` ⇒ 读回 **231.2**（**不是** 231.15，也不是 231.1）。 ⇒ 若业务要求"**不可表示即失败**"，请调用方先用 `decimal.Round` 自行定标， 再传入本方法；本方法**不会**因为"丢了一位小数"而报错。

    TryToInteger(byte[], bool, out long, out string)

    把线上字节（驱动返回的原始值区：低字节在前、已 -0x33、BCD 编码） 解码为未缩放的整数幅值（不含小数位）。

    本方法只做 ① 反序 + ② BCD→整数；小数位由 ToEngineering(byte[], int, bool) 应用。
