    Class DeltaAsAddressMapper

    台达 AS 系列 Modbus 地址映射器。

    源自 HSL DeltaASHelper。

    [!!]【2026-11-14 审计结论】**本类各器件分支没有"官方范围守卫"，这不是遗漏**： 仓内**没有台达 AS 系列官方器件范围表**，HSL 的 AS 路径同样**只给基址、无范围校验** ⇒ 按项目纪律（无官方原文或 ≥2 个独立来源时不得凭猜加界）**刻意不加** —— 猜错的守卫会把**合法**地址判为越界，比"少加界"更糟。

    若将来取得台达 AS 官方表：请按 `DVP` 类的写法逐器件加 `> 上限 ⇒ return null`， 并补"边界内侧仍可用"的用例（参考 `DeltaDvpAddressMapperOfficialTests`）。 审计台账见 `docs/drivers/品牌地址映射系统排查_缺陷类别与线索_20261114.md` §四点十六。
