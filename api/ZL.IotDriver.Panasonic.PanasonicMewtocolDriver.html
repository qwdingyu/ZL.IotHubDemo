    Class PanasonicMewtocolDriver

    松下 Mewtocol 串口协议驱动（RS232）。

    协议帧格式： - 命令帧：% + 站号(2ASCII) + # + 命令(2ASCII) + 地址(7ASCII) + BCC(2HEX) + \r - 响应帧：% + 站号(2ASCII) + $ + 状态码(2ASCII) + 数据 + BCC(2HEX) + \r

    Parameters
    Type Name Description
    string portName

    串口名称，如 COM1
    int baudRate

    波特率，默认 9600
    int stationNo

    站号，默认 1。合法范围 1~255（0 视为未指定 ⇒ 取 1）。
    Remarks

    ⚠️ 站号以 2 位十六进制 ASCII 编码（与 HSL PackPanasonicCommand:166 station.ToString("X2") 及仿真器 Substring(1,2), 16 两源一致 ✓）⇒ 站号 > 255 会渲染成 3+ 字符 ⇒ 帧结构被破坏 ⇒ 必须快速失败 ✗→✓（2026-11-02 官方手册裁定后补）。 📌 官方手册（WUME-MEWCP-03）站号规范原文：「Two-digit decimal 01 to 32, EE, or FF」； 「FF = 全局广播，不返回响应」⇒ 配 FF 时读操作将按超时失败（协议行为，非缺陷 ✓）。
