    Class MemobusAddress

    Memobus 地址：MFC（主功能码）+ SFC（子功能码）+ 起始地址 三者合一。

    支持三种写法（与 HSL 一致）：

    • 100 —— 纯数字（MFC 默认 32、SFC 默认 3）
    • 100.3 —— 位地址 ⇒ 起始 = 100×16 + 3 = 1603
    • mfc=32;x=3;100 —— 富地址（显式指定 MFC / SFC）

    IsWordBitForm

    地址是否以 word.bit 形式给出（如 100.3）。

    【为什么要这个标志】该形式下 AddressStart 是 **`word*16+bit` 位编码**， 与"纯数字"形式**不是同一坐标系**（见 AddressStart 注释的实测对照表）。 ⇒ **写分片只能对"纯数字 + 字区"做按点偏移**；本标志为 `true` 时必须走守卫。
