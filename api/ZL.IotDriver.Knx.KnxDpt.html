    Remarks

    两类支持方式（务必区分，别把"能读"当"懂物理单位"）：

    1. 带物理语义：1.001（布尔）、5.001（0..100 %）、9.001（温度 ℃）—— 做了业务换算 ✓
    2. 原始值：6.0xx（1 字节有符号）、7.0xx（2 字节无符号）、8.0xx（2 字节有符号）、 12.0xx（4 字节无符号）、13.0xx（4 字节有符号）、14.0xx（4 字节 IEEE754 浮点） —— **不做子类型分辨率缩放**（例如 13.001 常见的 0.01 系数、6.001 的 % 换算）✗ ⇒ 读到/写入的是**原始整数或浮点**，需要业务单位请在上位机换算。

    为什么这样切：各子类型的分辨率（0.01 / 0.1 / 1 …）**必须**按官方 DPT 表逐条核对， 而本机**没有**该表（`docs/588` 的记录里也没有）；凭印象加系数就是"静默给错值" ✗ ⇒ 宁可只给原始值 + 明确报边界，也不猜。
