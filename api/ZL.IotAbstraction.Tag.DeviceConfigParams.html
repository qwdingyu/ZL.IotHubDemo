    Class DeviceConfigParams

    DeviceConfig 的无状态参数读取辅助（单一实现）。

    2026-11-09 从 ZL.IotEngine.Native.NativeProtocolRegistry 提取： 这些方法同时被 Engine 的注册表和 Driver 的 NativeDriversPlugin 使用 ⇒ 放在契约层，避免 Driver 为了读参数而反向依赖 Engine。

    行为与原实现逐字一致：null ⇒ 默认值；已是目标类型 ⇒ 直接返回；否则 TryParse，失败回退默认值。
