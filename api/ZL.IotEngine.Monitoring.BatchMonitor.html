    Class BatchMonitor

    调试监控批量采集引擎。

    职责：将标签列表批量合并读取，支持协议自适应地址格式和块健康管理。

    设计原则：纯逻辑层，不依赖任何 UI 框架（WinForms/WPF/Avalonia）。
