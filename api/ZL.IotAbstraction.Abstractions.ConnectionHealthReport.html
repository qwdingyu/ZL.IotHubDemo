    Class ConnectionHealthReport

    PLC 连接健康报告——定期生成的连接状态体检结果。

    在工控现场，PLC 与上位机之间的通讯可能因网络抖动、PLC 重启、网线松动等原因中断。 健康报告提供多维度的连接质量指标，供上层系统（运维看板、告警引擎）使用： - 成功率低于阈值 → 触发告警； - 距上次成功时间过长 → 判定为"疑似断连"； - 心跳失败次数 → 触发重连策略。
