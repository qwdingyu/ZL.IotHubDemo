    Class MelsecFxOverTcpDriver

    三菱 FX 串口转网口驱动（串口帧经 TCP 透传，"串口服务器"形态）。

    【2026-10-26 新增，docs/todolist ④】帧构建（ENQ/命令/求和）/ 收帧 （STX/ETX/校验和）/ NAK 识别 **单源复用** MelsecFxDriver ✓ —— 本类只覆写传输层 3 缝与连接管理（与 PanasonicMewtocolOverTcpDriver 同模式 ✓）。

    【GOT 中转支持（2026-10-28，docs/490 §4.1-1 → docs/491 补充）】 UseGot = true 时走「FX3U 编程口 → GOT 触摸屏 → 上位机以太网」形态： 当前代码尝试封装 GOT 头尾并发送登录序列；不代表 GOT 已验证可用。 【2026-10-28 安全复核，docs/502】父类 ENQ+WR/BR 内帧与 HSL STX+E00 方言不同； 发送转义及响应剥尾已按 HSL 包装函数修正，尚未实测。未取得足以裁定 GOT 中转语义的独立证据， 不得把现有实现直接注册为生产可用协议。父类协议解析保持不变。

    【验证边界】FxGotFrameCrossTests 的旧脚本端不回复登录数据，且未检查连接结果； 不能作为登录后读请求或真实 GOT 互通证据。无 GOT 真机验收结论，详见 docs/502。
