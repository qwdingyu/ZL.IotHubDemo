    Class NormalWriteRequest

    普通写入请求——可被合并去重的低优先级写入操作。

    在工控场景中，HMI 界面上的滑块或输入框可能频繁触发写入请求（如用户拖动滑块）， 但 PLC 通讯带宽有限，不能每次都实际发送。NormalWriteRequest 被放入写入队列后， 如果同一地址有新的请求到来，旧请求可以被合并/丢弃（取最新值）， 从而减轻 PLC 通讯压力，避免"写入风暴"。

    通过 System.Threading.Tasks.TaskCompletionSource<TResult> 将异步结果返回给调用方， 调用方 await 即可获知写入是否成功。
