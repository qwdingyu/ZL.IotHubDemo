    PlcValidationTool

    PlcBase 事件链路验证工具。 在不依赖真实 PLC 的情况下，依次注入两轮标签值快照，校验：

    1. 标签加载是否正常
    2. 值变化检测 → PlcNotificationHub.Instance.TagChanges（UI 监控事件）是否触发 （注意：本工具的 PureSimDriver 自持缓存与变化检测，【不】调用 DeviceRoot.ProcessTagValueChange——那是 BatchEngine 的通路）
    3. TagType=M 的标签值变化后，OnTriggerDataChange（业务事件）是否触发
    4. PlcNotificationHub 是否收到变化事件，且携带正确 DeviceId
