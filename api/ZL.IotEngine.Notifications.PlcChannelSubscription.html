    Class PlcChannelSubscription

    基于 System.Threading.Channels 的订阅包装器。

    工控场景中的设计意图： 回调式订阅（Action）适合简单场景，但在 async/await 消费模型中不够优雅。 本类将中枢的回调桥接为 Channel，使下游可以用 await foreach 异步消费事件流， 天然支持背压（bounded channel + DropOldest）和取消。

    典型用法： 

    using var sub = hub.SubscribeChannel(options, capacity: 256);
await foreach (var evt in sub.Reader.ReadAllAsync(cts.Token))
{
    // 处理事件：更新 UI、写入数据库、转发给 MES 等
}
