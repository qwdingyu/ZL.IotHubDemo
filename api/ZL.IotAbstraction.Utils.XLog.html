    Class XLog

    进程内日志门面：按级别/前缀分文件，按大小与日期切换，线程安全，零第三方依赖。

    全部成员都是静态的；本类**从不被实例化**。

    Configure(Action<XLogOptions>)

    调整日志参数并立即生效（关闭已打开的 writer，下一条日志按新参数重建）。

    建议在进程启动时调用一次；运行期调用是线程安全的，但会短暂关闭文件句柄。
