    DlmsDriver

    DLMS/COSEM 智能电表协议驱动（串口/光电）。

    协议特点： - 使用 HDLC 封装，帧起始/结束为 0x7E。 - 支持 OBIS 地址编码（如 1.1.0.0.0.255 表示正向有功电能）。 - 采用 CRC16-CCITT 作为帧校验序列（FCS），多项式 0x8408，初始值 0xFFFF，最终 XOR 0xFFFF。 - 响应支持 ASCII 数值（如 "123.45"）和二进制 HDLC 帧两种格式。

    当前为简化实现，仅支持 ReadRequest（功能码 0xC0）和单变量读取。 写入操作暂不支持。
