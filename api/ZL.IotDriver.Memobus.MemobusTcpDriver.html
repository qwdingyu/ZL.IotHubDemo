    地址支持 100 / 100.3 / mfc=32;x=3;100 三种写法 ✓

    EndianConverter

    字节序：CDAB（字交换大端）—— 由端到端实测确证，不是照抄 HSL 源码 ✗

    【证据】仿真器 `ProtocolWireOrder`： 「【2026-10-15 实测更正】安川 Memobus 的**载荷**实测为大端 （HSL `MemobusTcpNet` 写 0x1234 → 内存落 `12-34`）」，标 `Verified` ✓

    ⚠️ 其 `:132` 注释仍写"小端"（**过期**）⇒ 以映射表为准 ✓

    🔴 **但"BigEndian"不等于"我方 `BigEndianConverter`(纯 ABCD)"** ✗： 实测（2026-10-28，交叉测试）用纯 ABCD 时 **Int32 双向均字交换** （写 123456789 读出 -854259877 = 0xCD15075B，恰为**一个字交换**）。 改用 **`CdabEndianConverter`** 后双向一致 ⇒ 本生态（HSL `RegularByteTransform` + 仿真器 WireCodec）对应的实际约定是 **CDAB** ✓ —— 以**实测**为准（AGENTS §22.4）✓
