    Class AsyncAutoResetEvent

    异步自动重置事件（Async AutoResetEvent）。

    在工控采集场景中，常用于"有新数据到达，唤醒等待的消费者线程"这类生产者-消费者模式。 与 System.Threading.AutoResetEvent 类似，但完全基于 async/await， 不会阻塞线程池线程，适合高并发采集场景下作为信号通知机制。

    核心语义：调用 Set() 后，下一个（且仅一个）WaitAsync(CancellationToken) 调用会立即返回， 之后事件自动重置为未触发状态。
