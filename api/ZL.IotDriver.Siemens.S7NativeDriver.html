    Class S7NativeDriver

    西门子 S7 的 DeviceBase 包装（薄壳）。

    真正的连接 / 批量读取 / 心跳 / 重连全部由 NativeUnifiedDriver 完成； 本类只负责： ① 缺省协议键设为 siemens-s7（保持原 new S7NativeDriver(config) 的用法）； ② 覆盖 S7 的批量地址格式（DB1.0 vs M0）； ③ 覆盖 S7 的读长度换算（字节 1:1）。

    ⚠️ 依赖前提：宿主必须引用 ZL.IotDriver（提供 siemens-s7 描述符）， 否则 Connect() 会报“不支持的协议类型”。这与所有 NativeUnifiedDriver 路径一致。

    S7NativeDriver(DeviceConfig)

    用同一份 DeviceConfig 构造：若调用方没有显式指定协议键， 则在进入基类构造之前补 siemens-s7。

    🔴 **为什么必须在 base(...) 参数里补，不能写在构造体里**： DeviceBase 的构造函数会 `Task.Run(ConnectInternalAsync)` 发起首连； C# 保证派生构造体晚于基类构造执行 ⇒ 若在构造体里补键，首连可能已经 在协议键为空时解析描述符（线程池调度竞态）。 因此这里把补键动作放进 `base(...)` 的实参求值阶段（先于基类构造）。
