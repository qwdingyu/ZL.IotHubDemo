    Class PlcReadBlockBuilder

    智能读取块合并构建器。

    核心职责：将大量散落的标签地址，按"地址相邻、同数据区"的原则合并为少量 PlcReadBlock。 工业现场的 PLC 通常有 PDU 大小限制（如西门子 S7-1200 为 240 字节）， 合并策略需要在"减少网络往返次数"和"不超出 PDU 限制"之间取得平衡。

    三个关键参数控制合并行为：

    • maxGap：两个标签间允许的最大字节空隙（空隙内无有效数据但仍需读取）
    • maxBlockSize：单个读取块的最大字节长度（不能超过 PLC 的 PDU 限制）
    • minEfficiencyPercent：最小有效数据占比（避免"读 200 字节只要 2 字节有用"的低效合并）
