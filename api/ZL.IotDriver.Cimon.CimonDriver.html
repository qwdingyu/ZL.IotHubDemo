    Remarks

    [!!]【2026-11-16 改为 protected virtual，仅为可测性】位写修好后需要无 I/O 断言"驱动真正发出的帧"（命令码 0x77、count=点数、payload 1 字节/点）。 测试子类覆写本方法即可捕获出帧（与 SiemensPpiDriver.SendCommandThenConfirm、 ModbusRtuDriver.WriteRegistersSingle 同款做法）。生产路径零行为变更。 改前已按 AGENTS §21.5-1 核查：无任何反射调用本方法。
