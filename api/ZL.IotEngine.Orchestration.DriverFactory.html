    Class DriverFactory

    统一驱动工厂 —— 对外的唯一推荐入口。

    路由策略：

    • 默认走 Native：无前缀（如 "siemens-s7"）或带 "native-" 前缀均走自研驱动。 Native 是零商业依赖的默认选择。
    • 显式走 HSL：Protocol 以 "hsl-" 开头，或传入 DriverBackend.Hsl。 仅在需要 HSL 独有能力时使用（需先调 XInit.EnsureInitialized()）。

    典型用法：

    // 最简：走 Native（推荐，无前缀即 Native）
config.SetParam("Protocol", "siemens-s7");
var driver = DriverFactory.Create(config);

// 订阅标签变化事件（必须通过 ITriggerableDriver 接口，不要通过具体类型判断）
// ✓ 正确：通过接口，新增驱动类型自动生效，无遗漏
if (driver is ITriggerableDriver triggerable)
    triggerable.TriggerDataChanged += (id, value, tag) => { ... };

// ✗ 错误：通过具体类型 switch，将来新增驱动时静默丢失事件
// if (driver is HslUnifiedDriver hsl)  hsl.TriggerDataChanged += ...
// if (driver is NativeUnifiedDriver nat) nat.TriggerDataChanged += ...

// 显式走 HSL（唯一走 HSL 的方式）
config.SetParam("Protocol", "hsl-siemens-s7");
var driver = DriverFactory.Create(config);

// 后续用法与 IPlcDriver 一致，无需感知底层
await driver.ConnectAsync(ct);
driver.DataCollected += record => ...;

    HslBackendFactory

    HSL 后端工厂（由 ZL.IotHub.X 注册）。

    首次读取且未注册时，会尝试反射自动发现 ZL.IotHub.X 并触发其注册 （只尝试一次，结果缓存）。这样消费方只需引用 X 包即可，无需改代码。

    之所以用委托而非接口：避免 Core 对 X 的任何编译期依赖，保持"X → Core"单向引用。

    显式注册方式：ZL.IotHub.X.Hsl.HslBackendRegistration.Register()。
