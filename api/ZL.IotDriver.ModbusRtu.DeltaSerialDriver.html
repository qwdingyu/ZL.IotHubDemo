    Class DeltaSerialDriver

    台达（Delta）Modbus RTU 串口驱动。

    帧格式 = 标准 Modbus RTU（继承 ModbusRtuDriver，零帧逻辑复制）✓

    地址格式 = 台达符号地址（`D100`/`M0`/`X5`/`S10` 等），由台达映射器转换， **与 `delta-tcp` 使用同一系列映射器** ✓

    字节序 = **CDAB**（与 `delta-tcp` 一致；HSL `DeltaSerial` 同口径）✓

    串口名（如 COM3 / /dev/ttyUSB0）。
    int baudRate

    波特率，默认 9600（台达出厂默认）。
    int dataBits

    数据位，默认 8。
    StopBits stopBits

    停止位，默认 1。
    Parity parity

    校验，默认 Even（台达 RTU 常用 8-E-1；可按现场改 None）。
    byte stationNumber

    Modbus 从站号，默认 1。
    int timeoutMs

    超时毫秒，默认 1500。
    DeltaSeries series

    台达系列，默认 Dvp。
