    Interface IModbusAddressMapper

    Modbus 地址映射器 —— 将品牌符号地址转换为标准 Modbus 寄存器地址。

    设计意图：组合优于继承。品牌 Modbus 驱动（Inovance/Delta/XinJE）通过持有 IModbusAddressMapper 实例来实现地址解析，而非多层继承覆写。
