    读取点表文件文本（BOM → 严格 UTF-8 → 历史 ANSI 回退）。

    public static string ReadAllText(string path, Encoding? legacyFallback = null)
    Parameters
    Type Name Description
    string path

    文件路径（不存在 ⇒ 抛 System.IO.FileNotFoundException，与 ReadAllText(string) 一致）
    Encoding legacyFallback

    历史文件的回退编码；null ⇒ 不兜底，直接抛 System.IO.InvalidDataException（默认）。

    **为什么默认不兜底**：静默兜底会让 GB2312 文件"读取成功但内容乱码"✗ —— 与"禁止静默兜底"原则冲突。行业口径（Java/.NET/Go）同样是"严格 + 响亮失败" ✓

    仅当**确知**该批文件是 Latin1 时，显式传 LegacyFallback ✓
