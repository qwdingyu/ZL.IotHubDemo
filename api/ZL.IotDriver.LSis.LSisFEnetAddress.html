    Class LSisFEnetAddress

    LSis FEnet 协议的地址（解析结果 + 归一化）✓。

    【唯一权威来源 ✓】本文件的每条规则均逐条核对自 **vendor 的 HSL 12.9.2** （`_vendor/hsl-decompile-13.0.3/HslCommunication.Profinet.LSIS/LSFastEnet.cs` ✓）：

    • AnalysisAddress —— 归一化规则（区域 / 单位 / 数字倍率）✓
    • GetDataTypeToAddress —— 数据类型判定 ✓

    ⚠️ 不得据 NuGet DLL 的运行时行为反推本规则 ✗ —— 两者在 MX 上行为不同 ✗（属 HSL 版本分歧 ✓，详见 docs/425 §4 坑 C ✓）。

    🔴 **【协议基准在此】完整协议详录见 `docs/429_LSis_FEnet协议详录_源码与实测全量对照`** ✓ —— 那里按"源码怎么说 / 实测怎么做 / 我们怎么实现 / 为什么"四栏并列写清了**每一条规则** ✓。 改本文件前**必须先读它** ✗，否则极易再次出现"看源码写错、看 DLL 又改回来"的反复 ✗ （本项目已在 LSis 上反复多次，全部记录在 `docs/429` §七 ✓）。

    【为什么必须"归一化"】FEnet 线上帧里送的是**归一化后的地址串** ✓ （形如 %DB100 ✓），而**不是**用户书写的 `D100` ✗。 归一化由 `AnalysisAddress` 完成 ✓；本类把它显式建模，便于单测与变异自检 ✓。

    用户书写的地址 ✓，如 D100 / MB100 / MW100 / MX10 ✓。

    ⚠️ **带 `%` 前缀的输入会被拒绝** ✗ —— 那是**归一化之后**的形式 ✓， 其数字**已乘过倍率** ✗（如 `%MW200` 的 200 已是 ×2 的结果 ✓） ⇒ 若再解析会**重复乘** ✗（实测 `%MW200` → `%MW400` ✗）⇒ **只接受用户书写形式** ✓。

    ⚠️ **带 `.` 的地址（如 `M100.5`、`IX0.0.0`）在 v1 被显式拒绝** ✗ —— 其归一化要走 HSL 的 GetBitIndexInformation（会**改写地址串** ✓，语义复杂 ✓）， **本版未实现** ✗ ⇒ **快速失败** ✓（**远优于静默算错** ✗）。 注意：实测 `IX0.0.0`/`QX0.0.0` 在仿真器下**确实可用** ✓， 故这是**已知的能力缺口** ✗（记入 `docs/425` ✓），不是"不可能" ✗。
