    Remarks

    [!!]【2026-11-14 审计结论】DR / IR / CF 三区没有"官方范围守卫"，这不是遗漏： 它们是 CV 系列器件（Omron_W227_CV区码… 给的是 IR0~IR2/DR0~DR2）， 而本驱动目标是 CS/CJ（及 NJ/NX） —— CS/CJ 侧仓内无这三区的范围依据 ⇒ 按项目纪律刻意不加。

    **已加守卫的 8 区**（依据 CS1G-H CPU 手册与 W342 §4-3）： `CIO ≤6143` · `W/H ≤511` · `A ≤959` · `D/DM ≤32767` · `T/CNT ≤4095` · `E ≤32767`。

    审计台账见 `docs/drivers/品牌地址映射系统排查_缺陷类别与线索_20261114.md` §四点十六。
