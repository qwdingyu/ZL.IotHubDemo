    Dnp3TcpDriver

    DNP3 主站（Master）TCP 驱动 —— 最小可用子集。

    当前能做什么：建立 TCP 连接、发 Class-0 读请求（可用作连通性探测）、 单点读（模拟量 AI<n> / 开关量 DI<n>）。

    当前不能做什么（刻意留白，见各方法 TODO）：写命令（Group12/40）、 应答聚合对象的完整解析、分片重组、确认帧（ACK）、链路复位/重试状态机、 事件数据（Class 1/2/3 主动上报）。

    ⚠️ 验证边界（务必知情）：

    • 链路层（帧头 CRC 覆盖 [0..7]、16 字节块 + 2 字节块 CRC、LEN 语义） 已按 opendnp3 源码核验，并有独立静态向量覆盖；
    • 应用层的限定符与对象头只实现了本站模拟器所用的那一种 （Group30 Var5 / Group1 Var2 + Qualifier 0x17）； 未与第三方设备交叉验证。接真机前必须按设备手册复核限定符与变体。
