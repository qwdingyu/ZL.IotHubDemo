    Class LSisFEnetDriver

    LS Electric（GLOFA / MASTER-K / XGB）FEnet 驱动 [OK]。

    【分层（本仓既定做法 [OK]）】

    • LSisFEnetAddress —— 地址解析与归一化 [OK]（**纯函数** [OK]，43 条门禁测试 [OK]）
    • LSisFEnetFrame —— 帧构造与解析 [OK]（**纯函数** [OK]，32 条门禁测试 + 黄金向量 [OK]）
    • 本类 —— 只做 socket 收发 + IPlcDevice 契约 + 许可门禁 [OK]

    【唯一权威基准 [OK]】`_vendor` 的 HSL 12.9.2（`LSFastEnet` [OK]）。 [!] **不得**据 NuGet DLL 反推 [X]（两者在 `MX` 上不同 [OK]，见 `docs/425` §4 坑 C [OK]）。

    【已实测确认的关键事实 [OK]】 ① **字节序 = 小端** [OK]（`docs/425` §9.1 [OK]：HSL 写 Int16 0x1234 ⇒ 线上 `34 12` [OK]）； ② 读的「字节数」是**字节数** [OK] 不是元素数 [X]（§4 坑 B [OK]）； ③ 位读走 **Individual** 结构 [OK]（§4 坑 A [OK]）； ④ 大长度读写**现已可用** [OK]（仿真器侧第 9 处缺陷已修 [OK]，实测至 1024 字节 [OK]）。

    【v1 已知限制 [X]】带 `.` 的地址（如 `IX0.0.0`）会被 LSisFEnetAddress **显式拒绝** [OK]（需复刻 HSL 的 `GetBitIndexInformation` [X]，v1 未实现 [OK]）。
