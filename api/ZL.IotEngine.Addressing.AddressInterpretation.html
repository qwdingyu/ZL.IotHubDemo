    Interpret(string, IAddressSemantics, string, string)

    解释一个地址（驱动权威优先）。

    🔴 2026-11-04 修真实缺陷：原实现只用 PlcAddressHelper 解析， 从不询问驱动 ✗ —— 而建块路径是**驱动优先**（`DeviceRoot` 把驱动作为 IAddressSemantics 传入 `PlcReadBlockBuilder`，仅当驱动**放弃**时才回退通用解析器）。 两处注释都写"与建块路径**同一个解析器** ⇒ 结论一致 ✓"，该说法**已过时** ✗

    实测分歧（MegMeet，已发布品牌驱动，同一进程直接对比）：

    地址     本 API 预测        驱动真实语义        分歧
M100     位100  Area=""    位2100 Area="M"     差 2000   （位区，单位=位号）
SM100    位100  Area=""    位4500 Area="SM"    差 4400   （位区）
X20      位32   Area=""    位16   Area="X"     差 16     （位区）
D100     字号100 Area=""   字号100 Area="D"    **一致**  （⚠️ 字区，单位=字号）
⚠️ **单位必须分清**：位区的 Address 是**位号**，字区的是**字号** ✗→✓
  （我初版把 D100 按位号比得"差 700"，属**单位混用的错误**，已订正）

    ⇒ 下游（`TagTableValidator` 与消费者的"守门人"用例）据此会**算错区与偏移** ✗✗

    修法：本重载**先问驱动**（与建块路径同款"驱动优先、通用回退"）； 驱动放弃（或未传）⇒ 逐字节走原路径 ⇒ 向后兼容 ✓
