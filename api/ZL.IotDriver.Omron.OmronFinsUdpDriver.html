    Class OmronFinsUdpDriver

    欧姆龙 FINS over UDP 驱动。

    FINS 帧构造/地址解析/数据类型转换**全部继承**自 OmronFinsDriver（与 TCP 版同帧 ✓）， 本类只把传输层从 TCP 流换成 UDP 数据报，并**去掉 FINS/TCP 头与握手** ✓

    ⚠️ UDP 无连接语义：ConnectServer() 仅记下默认对端， 不会因"对端未监听"而失败（UDP 特性，非缺陷）✓

    DoTcpHandshake()

    FINS/UDP 无握手 ⇒ 覆写为空实现。

    ⚠️ 这是与 TCP 版最本质的差异：TCP 版必须发 `[FINS][12][0*8]` 并校验状态码， 而 UDP 直接发 FINS 命令帧即可 ✗

    ⚠️ 副作用：TCP 握手会**从响应里取 SA1/DA1**；UDP 取不到 ⇒ 保持父类默认值，需由配置显式指定本机/PLC 节点号（见注册表 `Sa1`/`Da1` 参数）✓
