    AllenBradleyCipDriver

    Allen-Bradley ControlLogix / CompactLogix CIP 协议纯 C# 驱动程序。

    直接基于 TCP Socket 实现 CIP 协议（EtherNet/IP），无需 libplctag 原生依赖。 协议帧结构对齐 HSL Communication 官方实现：PackRequestHeader + PackCommandService + PackCommandSpecificData。 支持全局标签、程序标签（Program:xxx.yyy）、数组元素（Tag[0]）等地址格式。
