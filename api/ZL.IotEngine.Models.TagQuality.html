    Enum TagQuality

    数据质量代码，对标 OPC DA/UA 标准中的 Quality 字段。

    在工控采集中，每个从 PLC 读取的点位都需要附带质量码， 上位系统（MES/SCADA/HMI）根据质量码判断数据是否可信： - Good(0xC0)：数据来自 PLC 实时读取，可放心使用； - Uncertain(0x40)：通讯短暂中断，保留最后一次有效值（"陈旧值"），上位可酌情使用或报警； - Bad(0x00)：通讯完全失败或地址配置错误，数据不可信； - Initializing(0x01)：设备尚未完成首次采集，值为默认值。

    质量码数值设计参考 OPC 规范的高/低两位编码方式， 便于通过位运算快速判断大类（Good≥0xC0, Uncertain≥0x40, Bad=0x00）。
