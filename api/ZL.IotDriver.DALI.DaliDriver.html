    Class DaliDriver

    DALI 照明控制协议驱动（通过 DALI-USB 网关转串口）。

    协议帧格式： - 前向命令帧：2 字节（地址字节 + 数据字节），地址范围 0-63（短地址），组地址 G0-G15，广播地址 BC/255。 - 返回帧：1 字节（应答/状态）。

    DALI 为单主多从总线协议，本驱动通过串口发送命令并读取单字节响应。 适用于灯控场景的调光、开关、状态查询。

    TypedAccess

    字节透明（一处声明同时决定读/写/位读三面）。

    [!!] DALI 的应答是 **1 字节状态位图**（如 `0x90`），**不是**"亮/灭"： 基类 `ReadBool` = `data[0] != 0` ⇒ 状态字节**几乎总是非 0** ⇒ **恒为 true**（无意义）。 要得到语义值须用 `DaliDriver.ParseStatus(rawByte)`。

    [!] 本驱动此前**只在注释里**警告"不要用 ReadBool"， 缺陷因此长期存在（2026-11-19 审查发现）⇒ 现改为**结构强制**。

    正确用法：`ReadBytes` 取 1 字节 ⇒ `ParseStatus` 解释。

    ParseStatus(byte)

    解析 DALI 状态字节（QUERY STATUS 应答，IEC 62386-102）。

    位定义（标准）：bit0=控制装置故障、bit1=灯故障、bit2=灯亮、 bit3=限值错误、bit4=渐变中、bit5=复位状态、bit6=短地址掩码、bit7=上电循环。

    返回：1=灯亮且无故障；0=灯灭或无响应（0xFF）；-1=故障。

    ⚠️ 【2026-10-22 C6 修复 ✗→✓】原实现把 bit0/1/2 当成"灯故障/灯亮/限值错误"， 整体错位 1 位 ⇒ 故障/正常反向 ✗。依据：IEC 62386-102 / Wikipedia DALI 命令表（2026-10-22 抓取）。
