    Class HartIpDriver

    HART-IP 驱动 —— 通过 TCP 网关与 HART 设备通信。

    协议要点： - 底层传输为 TCP，端口默认 5094。 - 应用层帧由 8 字节 HART-IP 头和 HART 原始帧组成。 - HART 命令 3 用于读取动态变量（PV/SV/TV/QV）。

    连接与收发复用 NativeDriverBase 的 _socket / TcpConnect / _stateLock（docs/62），避免并行 TcpClient 导致 IsConnected 恒为 false。
