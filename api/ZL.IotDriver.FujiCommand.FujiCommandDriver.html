    EndianConverter

    字节序：大端（ABCD）。

    【依据】HSL `FujiCommandSettingType` 构造用的是 `new ReverseBytesTransform()`，而该类源码**仅设 `DataFormat = ABCD`** （无任何 override）⇒ 与 `RegularByteTransform(ABCD)` **行为等价** ⇒ 我方对应 **`BigEndianConverter`（纯 ABCD）** ✓

    🔴 **实测排除了两个错误选项**（AGENTS §22.4，依次试过再定）： · `CdabEndianConverter`（字交换大端）⇒ Int32 双向**字交换** ✗ · `LittleEndianConverter`（DCBA）⇒ **16 位即字节交换** ✗ · **`BigEndianConverter`（ABCD）⇒ 16/32 位双向一致** ✓
