    UnicastTargetIp

    单播模式的目标 IP（null = 用定向广播，即协议默认行为）。

    **为什么需要**：原文（`docs/drivers/CCLinkIEFieldBasic.md` §2.9）明确 「主站发**定向广播**」。但在以下场景**收不到**：

    • **同机联调**（主站与从站在一台机器）—— 实测 macOS 上从站绑 `0.0.0.0` 收不到发往 `127.255.255.255` 的定向广播（Linux 同类问题见原文平台差异表）
    • 模拟器/仿真器部署在回环地址

    **证据依据**：原文同时要求「一机多主/从必须不同子网」—— 说明同机本就是"特殊场景"，需要专门手段。设为单播 IP 即进入该模式。
