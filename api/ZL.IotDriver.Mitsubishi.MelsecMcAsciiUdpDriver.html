    Class MelsecMcAsciiUdpDriver

    三菱 MC 3E ASCII over UDP 驱动。

    ASCII 帧构建/解析/地址换算**全部继承自** MelsecMcAsciiDriver （与 MC-ASCII-TCP **逐字节同帧**），本类只把**传输层**换成 UDP 数据报 ✓

    ⚠️ UDP 无连接语义：ConnectServer 仅记下默认对端， 不会因"对端未监听"而失败（UDP 特性，非缺陷）✓
