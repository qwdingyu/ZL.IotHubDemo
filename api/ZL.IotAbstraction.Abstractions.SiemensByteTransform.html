    Class SiemensByteTransform

    西门子 Big-Endian（ABCD）字节序转换器。

    西门子 S7 协议使用 ABCD（Big-Endian）字节序，与 x86/x64 的 DCBA（Little-Endian）相反。 此实现完全自有，不依赖 HSL.Communication。

    【2026-11-05】原还实现冗余的 `IByteTransform`（HSL 镜像接口，仅本类引用）⇒ 已删除该接口， 本类只保留**活契约** `IEndianConverter`（X 侧适配器与驱动均用它）✓ 设计决策：IEndianConverter 适配由 HslEndianAdapter 桥接类完成， 避免在 Abstractions 项目中产生对 ZL.IotAbstraction.Abstractions.IEndianConverter 的循环引用。
