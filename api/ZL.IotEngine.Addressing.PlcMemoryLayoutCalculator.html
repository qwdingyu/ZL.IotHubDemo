    Class PlcMemoryLayoutCalculator

    PLC 点位物理内存布局计算器（单一事实源，docs/405 阶段二）。

    核心职责：统一计算一个 TagItem 在 PLC 底层物理内存中占用的**真实物理字节跨度**， 供块构建器（PlcReadBlockBuilder）、块定义（PlcReadBlock） 与值提取器（PlcValueExtractor）共同遵循，杜绝多处各写一套导致的尺寸失真。

    【四大物理不变量】 1. 定长类型：字节数由规范类型固定（如 short=2, int=4, double=8）； 2. 位地址（bool）：占用该位所在的 1 个字节； 3. 西门子 S7 STRING[M]：物理占用 = 业务容量 M + 2 字节前导头； 4. 西门子 S7 WSTRING[M]：物理占用 = 业务字数 M * 2 + 4 字节前导头； 5. Raw / byte[]：物理占用 = 声明字节数 M。
