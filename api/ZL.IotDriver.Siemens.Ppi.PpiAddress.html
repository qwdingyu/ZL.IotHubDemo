    Class PpiAddress

    PPI 地址解析结果：区域码 + DB 号 + 位地址起点。

    ⚠️ AddressStart 的单位是**位**（bit），不是字节 ✗ —— PPI 的地址字段按位表达（见 CalcAddressStart(string, out int, out string)）
