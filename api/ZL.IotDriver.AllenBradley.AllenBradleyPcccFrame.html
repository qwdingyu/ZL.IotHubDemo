    DescribePcccExtSts(byte)

    PCCC EXT STS（扩展状态）→ 官方语义。仅当 STS == 0xF0 时存在。

    【出处（AGENTS §22.5 四要素）】 ① 值：官方十六进制码（`0`~`19`、`1A`~`1E`、`22`~`24`，**共 34 码**）； ② 含义：见下各分支（官方英文原文保留，自行意译有失真风险）； ③ 证据：`docs/evidence/Rockwell 1770-rm516.pdftotext-layout.txt` **Chapter 8 §EXT STS Codes for CMD 0F**（p.8-4，见 `EXT STS Codes for CMD 0F` 一节）； ④ 判定：**对齐官方 34 码全集** [OK]。

    【适用范围】官方原文：「Definitions for this byte vary, depending on the **command code**」—— · CMD `00`~`08` ⇒ **无** EXT STS 字节； · CMD **`0F`** ⇒ 本表（DH/DH+），**本驱动使用 CMD `0x0F`** ⇒ 适用 [OK]； · CMD `0B`/`1A`/`1B` ⇒ DH485 码表（p.8-5，**本驱动不用** ⇒ 未收录）。

    【复核命令】 grep -n "EXT STS Codes for CMD 0F" "docs/evidence/Rockwell 1770-rm516.pdftotext-layout.txt"

    【证据等级：B】官方 PCCC EXT STS 段（**原文不在仓内**）＋ 自述 ⇒ **可参考，不宜直接当真机依据**；取得官方原文后须复核。

    [!!]【2026-11-16 订正】原注释写「完整映射 Local / Remote / **EXT STS**」—— **不准确** [X]：本方法只处理 **STS**（单字节），**EXT STS 是另一个字节**（见 `DescribePcccExtSts`）。 官方 `EXT STS Codes for CMD 0F` 共 **34 码**（p.8-4），本方法不含。
