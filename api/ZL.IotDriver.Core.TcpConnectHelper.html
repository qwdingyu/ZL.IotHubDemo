    Class TcpConnectHelper

    带超时的 TCP 连接（"异步 BeginConnect + 超时 + 失败即安全关闭"）的唯一实现。

    【为什么要它（docs/292）】该模式此前有 **3 份**几乎逐字相同的实现： NativeDriverBase 一份，另有两个**直接实现 IPlcDevice、不继承基类** 的驱动（MitsubishiMcDriver / OmronFinsDriver）各自复制一份。 三者都把 EndConnect 的异常**整个吞掉**（catch { }）⇒ 失败时调用方只看到"连接失败"这一句，**真实的失败原因（如 connection refused）被丢弃** ✗ —— 与本仓反复治理的"**静默**"族缺陷同源（docs/148 D-5、docs/283 §2）。

    【本实现的行为】**与原来逐条等价**，只多做一件事：**保留异常文本用于诊断** ✓

    1. IP 解析失败 ⇒ Fail("无法解析 IP: …")（原语义）；
    2. 超时 ⇒ 安全关闭 socket 后 Fail("连接超时(…ms)")（原语义）；
    3. 未连上 ⇒ 安全关闭 socket 后 Fail("连接失败: <真实原因>")（**新增原因** ✓）；
    4. 成功 ⇒ Ok（状态位由调用方自行置位）。

    失败路径统一复用 CloseSafely(ref Socket) ⇒ 与"安全关闭"同一条规则 ✓。
