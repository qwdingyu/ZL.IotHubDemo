    Class MTConnectDriver

    ⚠️ 「周期性」与「JSONPath 取值」均未实现 ✗ —— 实际只做单次 GET 并返回整段 JSON ✓ （见 docs/433 §二十七 ✓：ExtractScalar<T> 零调用 ✗、PollIntervalMs 从未被读 ✗）。

    适用场景：数控机床（CNC）数据采集，符合 MTConnect 1.5+ 标准。 地址格式：AgentUrl|JSONPath，例如 http://agent.example.com/current|$.Devices[0].Components[0].DataItems[0].Value。
