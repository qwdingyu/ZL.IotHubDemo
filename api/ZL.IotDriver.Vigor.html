    Namespace ZL.IotDriver.Vigor

    Classes

    VigorAddress

    Vigor 地址：区域码（DataCode）+ 起始地址。

    ⚠️ 该协议有**临界映射**（与 HSL 一致，**逐项对齐**）：

    • 位：M≥9000 ⇒ 映射到 SM（码 148、起始归 **0**）
    • 字：D≥9000 ⇒ 映射到 SD（码 161、起始 **减 9000**）
    • 字：C≥200 ⇒ 码 **173**（否则 172）

    VigorDriver

    Vigor TCP 驱动。

    ⚠️ 字节序 **小端**（仿真器 `ProtocolWireOrder`：`Vigor` 实测为小端 ✓）

    ⚠️ 地址有**临界映射**（M≥9000⇒SM / D≥9000⇒SD / C≥200⇒码173）见 VigorAddress ✓

    VigorSerialDriver

    丰炜（Vigor）真串口驱动。

    帧/地址**静态复用** ZL.IotDriver.Vigor.VigorFrame / VigorAddress ⇒ 零复制 ✓

    收帧三阶段**逐行同构** VigorDriver.Exchange（见文件头说明）⚠️

    ⚠️ **未真机验证**；真串口收发路径无自动化覆盖（本机无串口设备）⚠️
