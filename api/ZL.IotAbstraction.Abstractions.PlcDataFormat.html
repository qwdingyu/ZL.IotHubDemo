    Enum PlcDataFormat

    数据格式（字节序）——定义 16/32/64 位数据的字节排列方式。

    命名约定：每个字母代表一个字节位置（A=最低字节, D=最高字节）

    ABCD大端序（Big-Endian）：D0 最高字节在最前
    DCBA小端序（Little-Endian）：D0 最低字节在最前
    CDAB字内字节交换：先交换 16 位字，再按大端排列
    BADC字内字节交换：先交换 16 位字，再按小端排列

    适用场景：汇川（Inovance）、台达（Delta）等 PLC 使用 CDAB 字节序。
