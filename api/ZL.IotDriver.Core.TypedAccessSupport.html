    Enum TypedAccessSupport

    驱动对类型化访问（ReadInt16 / ReadFloat / ReadString / Write(address, 数值) / ReadBool） 的支持声明。由 TypedAccess 声明，一处决定读/写/位读三面。

    Namespace: ZL.IotDriver.Core
    Assembly: ZL.IotDriver.dll
    Syntax
    public enum TypedAccessSupport

    Fields

    Name Description
    ByteTransparent

    字节透明：值区是原始字节（BCD / 带指数 / 位图 / 对象载荷等）， 不能按类型直接解释 ⇒ 类型化读 / 写 / 位读全部响亮失败， 调用方必须改用 ReadBytes / Write(address, byte[]) 并自行解码。

    已确认属于本类：DLT645、CJT188（BCD + 低字节在前 + 每 DI 小数位）、 DALI（原始状态位图）、DNP3（原始对象载荷）。
    Native

    原生支持（默认）：值区可直接按 short/int/float/string 解释。

    适用于：PLC 系（寄存器语义）、以及驱动内部已解析成 `double`/`float` 并按 `EndianConverter` 编成字节的协议（MBus / DLMS / HART-IP）。
