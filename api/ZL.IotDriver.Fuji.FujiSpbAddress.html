    Class FujiSpbAddress

    富士 SPB 地址。

    格式：<前缀><十进制地址>[.<位号>]，如 X10 / M10 / W9.3。

    ⚠️ 地址**不做减一**（实测 HSL 亦不减）—— 与三菱/OMRON 的一基归一约定不同 ✗

    ToSwappedDecimal(int)

    把整数值转成 SPB 线格式的 4 位十进制、前后两位互换 形式。

    实证（HSL `FujiSPBHelper.AnalysisIntegerAddress` 与仿真器 `FujiSPBServer.ToSwappedAddress` 完全一致）：

    10  → "0010" → "1000"
1   → "0001" → "0100"
256 → "0256" → "5602"
