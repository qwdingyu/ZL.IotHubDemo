    Class PlcAddressParseOptions

    地址解析的可配置选项。 允许调用方指定目标协议画像、严格模式、Modbus 基址偏移以及符号地址映射表。

    ModbusOneBased

    Modbus 语义地址的基址模式。 true（默认）: 地址从 1 开始计数（如 40001 表示保持寄存器第 0 个），符合 Modbus 标准文档习惯； false: 地址从 0 开始计数，部分国产 PLC 使用此约定。

    SymbolAddressMap

    ForProfile(PlcAddressProfile)

    ⭐ 设备画像 ⇒ 解析选项 的单一真源工厂（2026-11-04 新增）。

    🔴 为什么必须有它：本仓曾有 **5+ 个**调用点各自手写 new PlcAddressParseOptions { ... }，而**参数不一致** ⇒ 同一点表地址 在不同路径解析出**不同结果** ✗✗

    实测证据（本轮）：

    • 块构建器用 { Profile, Strict = true }， 而 `DeviceRoot`(2 处)/`BatchMonitor`/`PlcValueExtractor` 只传 { Profile }（Strict=false）✗
    • `Strict` **确有影响**：实测 **29 组**解析结论不同 —— 如 `Siemens + "W10"`：{Profile} ⇒ `W@10+0`，{Profile,Strict} ⇒ **解析失败** ✗

    语义（与 `PlcReadBlockBuilder` 的设计意图一致）： 画像已声明 ⇒ 严格按画像，不回退；画像不认的写法**明确解析失败**， 远好于被别的协议规则误读成错位置 ✓

    画像 = Any ⇒ 返回 null （= 解析器默认选项）⇒ 逐字节保持原行为 ✓
