    IoMetric

    IO 操作指标累加器——线程安全地记录某类 IO 操作的统计数据。

    在工控采集中，每次 PLC 读写操作都应记录耗时和成功/失败状态， 用于后续的性能分析和故障诊断。例如： - 如果平均耗时突然升高，可能说明 PLC 通讯负载过重或网络拥塞； - 如果成功率下降，可能说明网线松动或 PLC 异常。

    使用 lock 保证多线程安全——采集线程和消费线程可能同时操作同一个 IoMetric。

    IoMetricSnapshot

    IO 指标不可变快照——从 IoMetric 中截取某一时刻的统计数据。

    快照设计模式（Snapshot Pattern）： 采集线程持续写入 IoMetric，报告线程通过 GetSnapshot() 获取一致性视图， 避免在读取过程中数据被并发修改导致"撕裂读"。

    PlcCollectRecord

    通用采集数据快照——一次批量采集的完整结果。

    在工控场景中，通常以"设备 + 工位"为维度，每个采集周期读取一批点位， 然后将结果打包为一个 PlcCollectRecord，交由上层（MES 入库、SCADA 显示、日志持久化）消费。

    设计要点： - Values 字典使用 OrdinalIgnoreCase 比较器，因为 PLC 地址不区分大小写（"DB1.DBD0" == "db1.dbd0"）； - MainCode 用于产线场景：当驱动层已识别到产品序列号时，可直接关联采集数据与产品追溯。
