    Class ValueScale

    工程量换算纯函数工具：工程值 = 原始值 × factor + offset。

    典型用法（应用层/展示层，不在 IotHub 内核）：

    // 传感器：原始量 2500 表示 25.00 ℃ ⇒ factor = 0.01, offset = 0
double eng = ValueScale.Apply(2500, 0.01);

// 4~20mA 变送器：原始 0..4095 对应 -40..+80 ℃
//   factor = 120.0 / 4095, offset = -40
double t = ValueScale.Apply(raw, 120.0 / 4095.0, -40.0);

// 写回时反解（保证与读方向对称）
double rawToWrite = ValueScale.Reverse(t, 120.0 / 4095.0, -40.0);

    🔴 设计约束（勿改）：

    1. **只做线性变换**。非线性（查表、开方、分段）请在应用层自己做 —— 一旦这里接受任意函数，就等于在 IotHub 里重新引入了"表达式引擎"， 而这正是明确拒绝的东西。
    2. 不做类型转换。输入输出都是 double， 要 float/short 请调用方自行转换 —— 避免在这里引入"取整策略"这种隐含语义。
    3. Reverse 不做除零保护以外的任何裁剪。返回值可能超出 PLC 数据类型范围， 是否截断由调用方决定（静默截断 = 制造假数据）。

    为什么是静态类而不是实例：无状态、无配置、可并发； 需要"带配置的换算器"时，调用方持有 (factor, offset) 即可。

    Reverse(double, double, double)

    工程值 → 原始值：raw = (engineering − offset) / factor。

    与 Apply(double, double, double) 严格互为反函数（浮点误差内）—— 这一点必须由调用方依赖：读用 Apply、写用 Reverse，才能保证读写对称。
