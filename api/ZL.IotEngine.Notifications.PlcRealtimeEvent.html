    Class PlcRealtimeEvent

    PLC 实时事件载体。

    由通知中枢（PlcNotificationHub）统一发布，下游消费者（SCADA/MES/WinForm UI）通过订阅接收。 每个事件携带全局递增序号（Sequence），用于消费位点跟踪和回放去重。 根据 Kind 不同，携带不同的载荷字段。

    Sequence

    全局递增序号（由中枢分配），单调递增，用于：

    1. 订阅去重：同一订阅内只投递比 LastDeliveredSequence 更大的事件；
    2. 消费位点（Ack）：下游通过 Acknowledge(consumerId, sequence) 报告消费进度；
    3. 回放定界：订阅建立时，回放不超过当前 LatestSequence 的历史事件。
