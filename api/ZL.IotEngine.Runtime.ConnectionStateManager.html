    IsConnected

    连接是否处于"可用"状态（包括 Connected、Degraded、Recovering、Suspect 四种）。 即使降级、恢复验证中或可疑，TCP socket 仍然存活，可以尝试读写。

    IsOperational

    连接是否处于"可正常操作"状态（排除 Suspect 可疑态）。 在 Suspect 态下，上层应暂停非关键写入，仅保留心跳探测。 Recovering 与 Degraded 同等待遇：恢复验证中仍可操作，否则采集循环 会因 !IsOperational 跳过读取，永远无法完成二次成功确认。

    强制标记为已连接状态（如 TCP 连接建立成功后调用）。 重置所有失败计数器，刷新最后成功时间。

    MarkDisconnected()

    强制标记为断开状态（如主动断开连接、TCP 异常关闭时调用）。 同时重置所有失败计数器，为下次重连做准备。

    RecordHeartbeatFailure()

    记录心跳探测失败。 心跳是轻量级的"连接存活"检测（如读取一个固定地址）， 连续失败说明网络可能中断，但业务操作不一定受影响。

    Declaration
    public void RecordHeartbeatFailure()

    RecordHeartbeatSuccess()

    记录心跳探测成功，重置心跳失败计数。 若当前为可疑态且业务操作无异常，恢复到正常连接态。

    Declaration
    public void RecordHeartbeatSuccess()
