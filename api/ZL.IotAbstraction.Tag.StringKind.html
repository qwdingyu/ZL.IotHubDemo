    Enum StringKind

    字符串存储格式枚举。

    西门子 S7 系列 PLC 的字符串存储有三种格式： - Raw：无前导符模式，直接存储字符数据（S7-200、Modbus 等） - S7String：西门子 STRING 格式（S7-1200/1500），前 2 字节为元数据 - S7WString：西门子 WSTRING 格式（S7-1200/1500），前 4 字节为元数据

    【设计目的】将字符串格式判断从设备级（DeviceRoot.DefaultStringKind）下沉到标签级， 使同一台 PLC 上可以混合使用不同格式的字符串标签。 例如 S7-1500 上可同时存在 String[20]（2 字节头）、Array of Char（无头）、WString[20]（4 字节头）。

    AbCipString

    罗克韦尔 AB (Logix) STRING 格式：前 4 字节为 DINT LEN（小端）， 其后为 SINT DATA[n] 字符数据（每字符 1 字节，按调用方 encoding 解码）。

    【布局依据（真机实测，非推断）】CompactLogix 5069-L330ERM fw38 探针： 结构实例 88 字节 = LEN 4 + DATA 82 + 2 补齐；用 86 字节写被拒（0x13）、88 字节成功 ⇒ LEN 在结构偏移 0、DATA 在偏移 4 ✓（见 AllenBradleyCipDriver.ReadStringAsync 的注释与）。

    ⚠️ **不得照抄 HSL 的偏移 2/6** ✗：HSL AllenBradleyConnectedCipNet 用的是 TransInt32(content,2) + GetString(content,6,n)，那是其**自身 218 分支读取上下文**的偏移 （其读取服务不同，响应前面多 2 字节结构句柄 ✗），**并非 Logix STRING 结构** ⇒ 照抄会让本来正确（真机验证过 ✓）的实现变错 ✗。本仓曾踩过此坑并已修正 ✓。

    None

    未配置（默认值）。 回落到设备级 DefaultStringKind 设置：S7String、S7WString 或 Raw。
    Raw

    无前导符模式：直接存储字符数据，无长度前缀。 适用于 S7-200、Modbus、及其他非西门子协议。
    S7SmartString

    S7-200 SMART 的 STRING 布局：1 字节头（Byte0 = 实际长度 ✓，没有容量字段 ✗）+ 内容 ✓。

    【为什么需要单独一项】S7-200 SMART 的字符串结构与 S7-300/400/1200/1500 **不同** ✗： 后者的 STRING 是 `[容量][实际]内容` ✓，而 SMART 是 `[实际]内容` ✓（无容量字段 ✗）。 这与"地址/COTP 握手都按型号区分"是同一类差异 ✓。

    【依据 = 参考实现 HSL 12.9.2（以代码为准 ✓）】`SiemensS7Helper.ReadString`： if (currentPlc != SiemensPLCS.S200Smart) { 读 2 字节头，用 Content[1] 作长度 } else { 读 1 字节头，用 Content[0] 作长度，内容从偏移 1 起 } ✓； `WriteString` 同理（SMART 分支先写 1 字节长度 ✓）。

    ⚠️ **不需要用户配置** ✓：由 ZL.IotDriver.Siemens.SiemensS7Driver 按 CpuType == S7_200Smart **自动选用** ✓ —— 它是 CPU 型号的事实、不是点表的选择 ✗ （与 `AbCipString` 由驱动自述同理 ✓）。

    S7SmartWString

    S7-200 SMART 的 WSTRING 布局：1 字节头（Byte0 = 实际字数 ✓）+ UTF-16LE 字符（不交换） ✓。

    【与常规 S7 WSTRING 的两点差异】① 头 1 字节而非 4 字节 ✗； ② 字符区是 **UTF-16LE（不逐字交换）** ✗ —— 常规 S7 是**大端**（逐字交换 ✓）。

    【依据 = HSL 12.9.2（以代码为准 ✓）】`ReadWString` 的 SMART 分支： 读 1 字节头 → 读 (1 + c[0]*2) 字节 → Encoding.Unicode.GetString(content, 1, len-1) ✓ —— **没有** `BytesReverseByWord` ✗；`WriteWString` 的 SMART 分支直接 plc.Write(address, value, Encoding.Unicode) ✓（同样不交换 ✓）。 注意其长度取**实收**（len-1）而非头值 ✓，本仓沿用"裁尾部 NUL"即可等价 ✓。

    S7String

    西门子 STRING 格式：前 2 字节为元数据（Byte0=最大长度, Byte1=实际长度），Byte2+ 为字符数据。 适用于 S7-1200/1500 的 STRING 类型。
    S7WString

    西门子 WSTRING 格式：前 4 字节为元数据（Byte0-1=最大长度, Byte2-3=实际长度），Byte4+ 为 Unicode 字符数据（每字符 2 字节）。 适用于 S7-1200/1500 的 WSTRING 类型。
