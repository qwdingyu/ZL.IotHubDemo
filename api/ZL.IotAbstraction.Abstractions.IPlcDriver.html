    Interface IPlcDriver

    标准化 PLC 驱动接口（推荐）：支持异步连接、高性能缓存读取、点位写入及触发式事件抛出。

    这是项目中 PLC 通讯的核心契约。所有驱动实现（HslUnifiedDriver 等） 均需实现此接口，使上层采集逻辑与底层协议解耦。

    设计要点： - 异步优先：ConnectAsync / WriteTagAsync 均返回 Task，避免阻塞采集线程。 - 缓存读取：GetCachedValue 从内存缓存中取值，无需每次发起网络 IO。 - 事件驱动：DataCollected 事件在批量采集完成后统一推送，支持 SCADA/MES 订阅。
