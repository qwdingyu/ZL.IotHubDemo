    Class CipTransport

    CIP/ENIP 的 TCP 传输层（自持 Socket 与状态锁，可独立使用）。

    线程安全：SendReceive(byte[]) 与关闭操作由内部锁串行化。

    Close()

    关闭当前连接但保留对象可复用（区别于 Dispose()）。

    [!!] 2026-11-16 修缺陷：原实现只有 `Dispose`（置 `_disposed` 且不可逆）， 而 `CipClient.Close()` 调的是 `Dispose` ⇒ **关闭后再 Connect 永远失败**（`_disposed` 已置位）[X] ⇒ 重连场景（`EtherNetIpDriver.ConnectServer` 先关旧连接再连）**结构上不可能成功**。
