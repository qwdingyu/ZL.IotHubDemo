    Class AsyncTimer

    基于 async/await 的周期定时器。

    在工控场景中常用于：心跳发送、连接保活、周期性巡检等定时任务。 相比 System.Timers.Timer，它不会在线程池上触发回调， 而是在 async 上下文中顺序执行，天然避免了回调重入问题。

    注意：此定时器会在上一次回调完成后才开始下一次等待， 因此实际间隔 = interval + 回调耗时，适合"固定间隔"而非"固定频率"场景。
