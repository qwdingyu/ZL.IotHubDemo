    Class ModbusErrorHelper

    Modbus 异常码到中文描述的映射（唯一实现）。

    【为什么要它（docs/293）】同一张表此前在 ModbusRtuDriver 与 ModbusRtuOverTcpDriver 各有一份 private static 副本（逐字相同）， 而这两个类**分属不同继承体系**（一个直接实现 IPlcDevice、一个继承 NativeDriverBase）⇒ 无法上提到基类，只能收敛为共享静态件。 一张表两处实现 ⇒ 将来改一处必漏另一处（本仓反复出现的根因， docs/271/284/287/288/291/292）。

    【口径】按 Modbus 规范（MODBUS Application Protocol V1.1b3）的公开异常码； 未登记码返回"未知异常码 N"（保留原行为，便于现场定位）。
