    Wrap(DeviceResult, string)

    给失败结果加上下文前缀，同时保留全部结构化字段 （ErrorCode / Kind / Owner / FailureTag）。

    🔴 为什么需要它：常见写法 Fail($"第一次握手失败: {inner.Message}") 只搬 `Message` ⇒ **丢掉** `Kind`/`ErrorCode`/`FailureTag` ✗ ⇒ 用本方法替代：inner.Wrap("第一次握手失败: ") ✓

    ⚠️ 前缀**不加**分隔符，由调用方自带（如 "握手失败: "）✓
