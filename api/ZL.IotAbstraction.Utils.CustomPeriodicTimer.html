    Class CustomPeriodicTimer

    跨框架版本的周期性计时器（Polyfill）。

    在工控采集主循环中，通常以 while(await timer.WaitForNextTickAsync()) 的方式 驱动采集周期。此计时器统一了不同 .NET 版本下的 API 差异：

    • .NET 6+：直接委托给微软原生的 System.Threading.PeriodicTimer（高性能、零分配）

    • .NET Standard 2.0 / .NET Framework 4.8：基于 System.Threading.Timer + TCS 自行实现

    这样上层业务代码可以用同一套写法，而无需关心运行时的框架版本。
