    Class SocketCloseHelper

    Socket 安全关闭的唯一实现。

    【为什么要它（docs/291）】"安全关闭 socket"这条规则此前在本仓有 **8 份实现**： SafeCloseSocket() 一份，另有 **7 个直接实现 IPlcDevice 的驱动各自私有的一份**。逐份比对发现它们**互不相同**， 其中最危险的分歧是：**5 份不会把 _socket 置空** ⇒ "安全关闭"之后仍留着 一个**已关闭的 socket 引用** ⇒ IsConnected 与后续连接复用都会看到不一致状态。 另有版本省略了 Connected 检查（对未连接 socket 调 Shutdown 会抛）。

    【本实现取"最防御"的语义】（即原 SafeCloseSocket() 的语义）：

    1. 仅当引用非空才处理；
    2. 仅在 Connected 为真时才 Shutdown（避免对未连接 socket 抛异常）；
    3. Shutdown 与 Close **各自独立 try** ⇒ 前者失败不影响后者；
    4. 最后把引用**置空** ⇒ 杜绝"已关闭引用"被复用。

    【调用方职责】_connected 之类的**状态位**由调用方按各自语义处理 （本仓既有实现一律先置 false，故调用方应在调用前完成），本方法只负责 socket 本身。
