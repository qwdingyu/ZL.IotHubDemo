    Class PlcAddress

    PLC 地址的统一归一化模型。 不论底层是西门子 DB、三菱 D、Modbus HR 还是欧姆龙 CIO， 所有地址经 PlcAddressHelper.Parse 后都会转化为本对象， 供后续的批量读取引擎（BatchEngine）和值提取器（PlcValueExtractor）使用。

    ByteOffsetIsBytes

    ByteOffset 的单位是否为字节（true = 字节；false = 协议原生地址单位，如"字/寄存器号"）。

    【2026-10-20 新增， §十一】解析层存在**两种单位** ✗：

    • 位地址规则（OmronWordBit / AbWordBit / MitsubishiModule / GenericWordBit / AltSeparator / BitArea）已用 `word*2` 或 `/8` 换算成**字节** ⇒ 本标志 = true；
    • 纯字地址规则（WordArea / Modbus HR·IR·4xxxx / PureNumber）保留 **字号（协议原生单位）** ⇒ 本标志 = false；
    • 字节寻址协议（西门子 S7 / Beckhoff ADS）的规则产出字节，但其协议单位本就是 1 字节 ⇒ 两种取值等价，不影响结果。

    ⚠️ 本标志**只声明单位、不改变 `ByteOffset` 的数值** ⇒ 所有既有断言（只比对数值）不受影响 ✓
