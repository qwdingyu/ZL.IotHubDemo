    Class FujiSphAddress

    富士 SPH 地址：类型码（TypeCode）+ 起始地址（+ 可选位号）。

    • M1.10 / M3.10 / M10.10 ⇒ 类型码 **2 / 4 / 8**（其它 M 编号不支持 ✗）
    • I10 / Q10 ⇒ 类型码 **1**
    • 可再带一级位号：M1.10.3 / I10.3（**含 A–F 按十六进制**）✓

    ⚠️ 起始地址按**十进制**解析（与 SPB 的十进制一致；Commando 的十六进制不同 ✗）
