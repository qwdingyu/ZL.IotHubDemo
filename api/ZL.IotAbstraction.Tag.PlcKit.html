    ConvertValue<T>(object)

    【已弃用】把 object 转换为 T —— 转换失败静默返回 default(T)。

    🔴🔴【2026-11-12 标记 `[Obsolete]`】**本方法有已实测的严重缺陷**： 上溢/下溢/格式错时**静默返回 `default(T)`** ✗ ⇒ 调用方**无法区分"转换成功且值恰为 0"与"转换失败"** ✗ ⇒ 实测后果：往 16 位点写 `70000` ⇒ **报成功但 PLC 落成 `0`**； `"abc"` ⇒ `0`；`3.7` ⇒ `4`（**7/7 报成功却值错**）✗✗

    **正解**：TryConvertValue<T>(object, out T, out string) —— 返回 `bool` ＋ 错误消息，越界/格式错**可判别** ✓ （底层 TryConvert(Type, object, out object, out string) 早已能检出， 本方法只是把它**吞掉**了 ✗）

    **为什么不直接删**：`public` API（已发布包）⇒ 按 `AGENTS §20.2` 标 `[Obsolete]` ＋ 指明替代品 ✓
