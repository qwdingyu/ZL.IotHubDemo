    Class PlcSubscriptionOptions

    订阅过滤与回放选项。

    在工控场景中，不同的下游消费者通常只关心部分标签或部分设备的数据。 例如：MES 系统只关心产量计数标签，SCADA 画面只关心某台 PLC 的全部标签， WinForm UI 只关心当前选中设备的连接状态。 通过此对象可精确控制订阅者收到的事件范围，减少无效数据处理开销。

    MatchAnyFilter

    过滤匹配模式：

    • true（默认）: OR 模式 —— TagIds 或 DeviceIds 任意命中即投递。
    • false: AND 模式 —— 同时配置了 TagIds 与 DeviceIds 时，需两者都命中才投递。

    ReplayLastCount

    订阅建立时立即回放最近 N 条事件；0 表示不回放（默认）。

    回放机制的工业场景意义： UI 页面打开时，需要立即展示最近的数据状态，而不是等待下一次采集周期。 例如：ReplayLastCount=10 表示订阅后立即收到最近 10 条事件，让 UI 快速渲染初始状态。

    注意：回放依赖中枢的有限缓存窗口（默认 5000 条），超出窗口的历史事件不在回放范围内。
