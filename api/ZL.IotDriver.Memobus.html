    Namespace ZL.IotDriver.Memobus

    Classes

    MemobusAddress

    Memobus 地址：MFC（主功能码）+ SFC（子功能码）+ 起始地址 三者合一。

    支持三种写法（与 HSL 一致）：

    • 100 —— 纯数字（MFC 默认 32、SFC 默认 3）
    • 100.3 —— 位地址 ⇒ 起始 = 100×16 + 3 = 1603
    • mfc=32;x=3;100 —— 富地址（显式指定 MFC / SFC）

    MemobusTcpDriver

    安川 Memobus TCP 驱动。

    ⚠️ 载荷字节序 **大端**（与 GE/Fuji 的**小端相反**）—— 由仿真器 `ProtocolWireOrder` **实测确证**（`Yaskawa = BigEndian, Verified`）✓

    地址支持 100 / 100.3 / mfc=32;x=3;100 三种写法 ✓
