    DefaultPort

    默认端口 507 —— ⭐ 官方默认值（2026-11-02 官方手册实证）

    出处：富士官方《SPH シリーズ CPU モジュール内蔵 Ethernet 通信編》FH193e （`docs/evidence/富士-FH193e-SPH-CPU模块内置Ethernet通信篇-日文官方.pdftotext-layout.txt`）：

    ① L677 原文：「ローダコマンド通信ポートの実ポート番号は、**自己基準ポート番号＋ 251** となります」； ② L678 原文：「デフォルト値は **256+251=507** となります」； ③ L641：自己ポート番号 251（ローダコマンドインタフェース）； ④ L5454（独立二次确认，E-mail 保留端口注记）：「256 ＋ 251 ＝ 507、256 ＋ 253 ＝ 509」； ⑤ 旁证：HMI 连接指南（Port no. 507 + 「add the offset 251」）与手册一致 ✓

    历史：原默认 **500** 无官方依据（2026-11-02 订正 ✗→✓）； HSL `FujiSPHNet` 的 18245 系**复制粘贴错误**（与 `GeSRTPNet` 同值，18245 实为 GE SRTP 端口 ✗）； 仿真器 `FujiSPHServer` 的 9120 为测试专用值（测试一律显式传 `SimulatorPorts.FujiSph` ✓）
