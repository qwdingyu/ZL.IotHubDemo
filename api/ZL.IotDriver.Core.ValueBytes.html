    Class ValueBytes

    把协议读到的值字节对齐/裁剪到调用方请求的字节数（AGENTS §21.1 契约的落地工具）。

    Remarks

    为什么必须集中一份：这类"补零/截断"看似简单，但**方向搞反就静默改值**。本仓已因此踩坑 2 次：

    1. BACnet：`UNITS=62`(0x3E) 被**右**补零成 `3E 00` ⇒ 读成 **15872** ✗ （同一属性在"批量读"与"单点读"两条路径各写一套规则，导致互相矛盾）
    2. KNX：4 字节整数（13.xxx）若用右补零同样会改值 ✗

    ⇒ 规则只允许有**一个**实现：浮点/字符串是**左对齐**（右补零）， 整数/枚举是**大端右对齐**（左补零、截断保留低位）。
