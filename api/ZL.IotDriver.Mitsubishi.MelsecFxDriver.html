    Class MelsecFxDriver

    三菱 FX 系列串口协议驱动（RS232/RS422）。

    协议帧格式： - 命令帧：ENQ + 站号(2ASCII) + PLC号(2ASCII) + 命令(2ASCII) + 延时(1ASCII) + 地址(5ASCII) + 字节数/点数(2ASCII) + 校验和(2HEX) - 响应帧：STX + 数据 + ETX + 校验和(2)
