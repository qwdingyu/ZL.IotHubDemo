    Interface IAreaAwareReader

    带数据区语义的批量读（可选能力，2026-11-03）。

    实现本接口的驱动会被采集引擎**优先**用于"块上带区名"的读取； 未实现的驱动**完全不受影响**（继续走 ReadBytes(string, ushort)）。

    ⚠️ 契约：length 与 ReadBytes(string, ushort) **完全一致 —— 恒为字节数**（AGENTS §21.1），返回前必须**截断到该长度** ✓
