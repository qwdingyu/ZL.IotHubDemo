    Class DisposeGuard

    「是否已释放」的唯一判定入口 ✓。

    【为什么需要它 ✗→✓】本仓的驱动存在**三种并行范式** ✓：

    1. 继承 NativeDriverBase（5 个驱动）✓ —— 基类只提供 EnsureNotDisposed()（**抛异常** ✗），**没有**"只判释放"的属性 ✗
    2. 继承 SerialDriverBase（5 个驱动）✓ —— 另一套平行实现 ✗
    3. 独立实现 IPlcDevice, IDisposable（9 个驱动）✗ —— **各自**声明 `_disposedFlag` 并**各自**写判定 ✗

    ⇒ 同一个问题「已释放之后该返回失败还是抛异常」在仓里曾有三套答案 ✗✓， 于是必然出现"改了 A 漏了 B、修了 7 个还剩 2 个" ✗（本项目真实发生过 ✓）。

    【本类的职责很窄 ✓】只回答"**这个标志位是否已置位**" ✓， **不碰 socket、不碰锁、不抛异常、无状态** ✓ ⇒ 可以直接用在**任何**范式里 ✓。 ⚠️ 它**不是**新的抽象层 ✗：没有接口、没有继承关系、没有依赖注入 ✓。

    【⭐ 关键纪律 ✗】**"已释放"和"未连接"是两件事，不可混淆** ✗✓ —— 本项目曾因用 `IsConnected`（同时含"未连接"与"已释放"两个条件 ✓） 去判定"是否已释放" ✗，把 `ConnectServer()` 的**正常连接流程也挡掉了** ✗， 导致 3 条 S7 用例变红 ✓。 ⇒ 需要"能否收发包"的判定用 `IsConnected` ✓； **需要"是否已释放"的判定一律用本类** ✓。

    Parameters
    Type Name Description
    int disposedFlag

    驱动的释放标志 ✓（约定：0=未释放、非 0=已释放 ✓）。

    ⚠️ 必须**按引用**传入实际情况下的那个字段 ✓（`ref`）—— 因为该字段会被其它线程在 `Dispose()` 里并发写入 ✓， 传值会读到**过期副本** ✗（编译器警告 CS0420 即针对此 ✓）。

    Returns
    Type Description
    bool

    true=已释放 ✓（调用方应返回失败 ✗，别抛异常 ✗）
    Remarks

    【为何用 Read(ref int) ✓】 释放标志由 Interlocked.Exchange 写入 ✓（见 NativeDriverBase.TryBeginDispose ✓）， 读取端必须同为获取语义 ✓，否则可能读到过期的 0 ✗ ⇒ 已释放却被判为未释放 ✓。

    Remarks

    【为什么还要"抛" ✗】本仓驱动的方法有两种契约 ✓，必须分开看 ✗：

    • 对外 IO 方法（`ReadBytes`/`Write` 等 ✓）—— 契约是「**已释放后返回失败，不得抛异常**」✓ ⇒ 这些地方**必须**用 IsDisposed(ref int) 判断后**返回 `DeviceResult.Fail`** ✗（不能用本方法 ✗）
    • 内部断言（如各驱动私有的 `EnsureNotDisposed()` ✓）—— 只是"不该走到这里"的防御 ✓ ⇒ 抛出是合理的 ✓

    ⚠️ 判断依据不是"我觉得"，而是自动枚举契约测试 ✓（AutoDisposeContractTests ✓）： 它对全部 30 个驱动验证"已释放后读/写必须返回失败" ✓ —— 只要它们全绿 ✓，就证明这些 EnsureNotDisposed 已不在对外可达路径上 ✓。

    🔎 **实测状态（2026-10-22 ✓，避免下次重新争议 ✗）**： 本方法**全仓零调用点** ✓（`grep -rn "ThrowIfDisposed" --include=*.cs ZL.IotEngine/` ⇒ 仅本文件定义处 1 条 ✓）⇒ 它属**为内部断言预留**的能力 ✓，**不是**对外 IO 的契约 ✗。

    📌 **历史包袱（已澄清 ✓）**：`NativeDriverProtocolTests` 里曾有 2 条用例断言 「Dispose 后**抛** `ObjectDisposedException`」✗（引入于 **2026-10-16** ✓）； 而现行契约测试建立于 **2026-10-19**（`a83f53d` ✓、**晚 3 天** ✓）⇒ 那 2 条**已过时** ✗， 已于 **2026-10-22** 更正为「**返回失败、不抛**」✓。 ⇒ **结论**：对外 IO **不抛** ✓；仅**内部断言**可抛 ✓。**不要再改回去** ✗。
