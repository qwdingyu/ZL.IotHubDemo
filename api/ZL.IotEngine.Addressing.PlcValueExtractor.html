    Class PlcValueExtractor

    从批量读取的 buffer 中提取各标签的实际值。

    工作流：BatchEngine 一次性读取 PlcReadBlock 对应的连续字节区域到 buffer， 然后由本类遍历块内每个标签，根据其地址偏移和数据类型， 利用 IEndianConverter 进行字节序转换，得到 .NET 强类型值。

    关键设计：IEndianConverter 封装了大小端（Endian）差异， 西门子 S7 是大端（Big-Endian），Modbus RTU 也是大端， 但某些国产 PLC（如汇川）可能使用小端，通过注入不同的 EndianConverter 即可适配。

    OnOutOfRange

    标签超出缓冲区范围回调（2026-10-17 收敛，docs/284 P2-C）。

    【为什么加它】此前"越界即跳过"是**静默**的：1 处 rel 预检 + **9 处** rel+N<=buffer.Length 分散判断 ⇒ ① 同一规则散在 10 处；② 值被静默丢弃（不产出、**不标质量码**、也不触发 OnUnsupportedDataType，后者只管类型码未登记）⇒ 下游无法区分"没有新数据" 与"当前值是旧值"（"静默数据缺口"族，见 docs/253/275/277）。

    【收敛后的形态】**一处**判定（最小 1 字节 + 定长类型的完整长度）+ **一处**上报（本回调） ⇒ 所有调用方（含 BatchEngine 那条对外 API 路径）**天然**都被覆盖，不必各自再打补丁。 参数为 (tag, 原因说明)。

    【语义等价性】定长类型的"需要字节数"取自与 switch 同一张表（TryGetFixedSize(string, out int)） ⇒ 与原先各分支的 rel+N<=buffer.Length **完全等价**；变长类型（string/byte[]）不在此判定 （仍按原样 Math.Min 夹取，保留"部分值"语义）；未登记类型由 OnUnsupportedDataType 负责。
