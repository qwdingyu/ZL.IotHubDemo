    Class MBusDriver

    M-Bus 仪表总线协议驱动。

    适用于水表、气表、电表、热表等 M-Bus 从站设备，通过串口 + M-Bus 电平转换器通信。 默认 2400bps、偶校验、8 数据位、1 停止位。
