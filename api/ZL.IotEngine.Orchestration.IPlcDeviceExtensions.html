    Class IPlcDeviceExtensions

    IPlcDevice 的泛型扩展方法集合——简化标量和数组的读写操作。

    设计意图：在不修改 IPlcDevice 接口的前提下，提供泛型 Read/Write 的便捷 API。 所有方法基于 ReadBytesAsync/WriteBytesAsync + IEndianConverter 实现， 零破坏性，不影响任何现有驱动实现。
