    Namespace ZL.IotEngine.Native

    Classes

    NativeProtocolRegistry

    原生协议注册中心：统一管理所有自研（不依赖 HSL）协议的客户端构造、 地址格式化与长度换算策略。

    NativeUnifiedDriver

    原生协议统一驱动 —— 项目的"瑞士军刀"核心执行面。 通过 NativeProtocolDescriptor + NativeProtocolRegistry 的组合， 在运行时根据 DeviceConfig 中的协议名称动态解析对应的原生客户端工厂、 地址格式化器和长度转换器，实现「一个 Driver 类覆盖所有自研 PLC 协议」。

    架构位置： DeviceRoot（采集调度 / 批量读取 / 心跳 / 重连） → DeviceBase（标签管理 + 批量读取引擎） → NativeUnifiedDriver（本协议驱动，负责底层连接与读写）

    支持的协议： Siemens S7 Native、Modbus TCP Native、三菱 MC Native、 三菱 FX Links Native、欧姆龙 Host Link Native、倍福 ADS Native、 Modbus RTU Over TCP Native、永宏 Fatek TCP Native、AB CIP Native。

    与 HSL 体系关系： HslUnifiedDriver → HSL 商业库（需授权） NativeUnifiedDriver → 纯 C# 原生（零依赖，MIT） 两者共享同一基类 DeviceBase，对上层完全透明。
