    Remarks

    为什么必须内置全量表（AGENTS §22.6 用户明确要求）：只回 error-code=31 这种裸数字，现场根本看不出"是对象不存在还是属性不支持" ⇒ 排障方向被误导。 官方表有多少码，这里就列多少码（我方不产生的码也列出，便于对照）。

    出处（双源交叉）：

    1. ASHRAE 135 **Clause 18**（"ERROR, REJECT AND ABORT CODES —— The Class and Code pairings are required to be used in accordance with Clause 18"）；
    2. 仓内参考实现 `_vendor/NewLife.BACNET/NewLife.BACnet/Base/BacnetErrorCodes.cs`（246 行， 逐条按 Clause 18 归类）；本表提取 **208 条唯一码值**（参考实现活跃码 209 条，唯一未列 = `65535 PROPRIETARY_LAST` —— 专有区间**上界标记**而非真实错误码；docs/589 §10.2 订正，原"全 214 条"与两侧来源都对不上 ✗）。

    本表未做的事（诚实边界）：非高频码只给**官方英文名**，未逐条译中文 （避免自造术语导致与官方文档对不上）；高频/我方会产生的码给了中文释义 ✓

    复核命令：

grep -c 'ERROR_CODE_' _vendor/NewLife.BACNET/NewLife.BACnet/Base/BacnetErrorCodes.cs
