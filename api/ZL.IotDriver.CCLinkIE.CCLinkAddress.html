    ResolveGlobalBit(int, out int, out int, out int)

    把全局位号换算为（占用站序号, 区内字节偏移, 位号）。

    **依据**：`cl_iefb_bit_calculate_areanumber`（cl_iefb.c:864-880）： 

    bitmask      = BIT(number & 0x07)      // 位号 = number % 8
byte_in_area = (number >> 3) & 0x07   // 区内字节 = (number / 8) % 8
area_number  = number >> 6             // 站号 = number / 64

    即每站 64 位（8 字节），跨站自动进位。
