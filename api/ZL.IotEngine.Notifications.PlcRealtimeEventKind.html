    Enum PlcRealtimeEventKind

    PLC 实时事件类型枚举。

    在工控采集场景中，中枢向下游（SCADA/MES/WinForm）分发的事件分为三类： 1) 标签值变化事件 —— 采集到的 PLC 寄存器数据发生变化时触发； 2) 连接状态事件 —— 设备连接/断线/Ping 状态变化时触发； 3) 设备运行状态事件 —— DeviceRoot 生命周期阶段（启动/停止/异常）切换时触发。

    Fields

    Name Description
    Connection

    连接状态事件：PLC 设备的连接状态（Connected）或心跳状态（PingOk）发生变化。 用于上位系统感知设备在线/离线，触发告警或 UI 状态切换。
    DeviceStateChanged

    设备运行状态事件：DeviceRoot 在启动/停止/异常等生命周期阶段切换时触发。 区别于 Connection：Connection 仅反映物理链路通断， DeviceStateChanged 反映"业务层"运行阶段（Running/Stopped/Error 等）。
    TagChanges

    标签值变化事件：一个或多个 PLC 标签（Tag）的值/质量码发生变化。 这是最高频的事件类型，对应工业现场的周期性数据采集推送。
